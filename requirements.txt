# Dependencies, pinned to the environment the pipeline is actually validated against.
#
# WHY EXACT PINS AND NOT FLOORS
# -----------------------------
# This project compares SNN FRAMEWORKS. A floor like `snntorch>=0.9.1` lets Colab and a
# laptop resolve to different library versions, and then the comparison is between
# versions rather than between frameworks -- with nothing in the output saying so. The
# four framework libraries, tonic and numpy therefore carry `==`. Verify with:
#
#     python check_env.py
#
# runs.csv records `framework_version` per row, so a drift is recoverable after the
# fact -- but only if someone notices. Pinning is the cheaper half of that.
#
# Versions below are what `python tests/run_all.py` (9 suites) passes against.

# ---------------------------------------------------------------------------
# PyTorch -- install FIRST, and pick the build that matches your machine.
#
# The pin is the version, not the build. A local wheel tag differs per platform
# (2.13.0+cpu here, 2.13.0+cu128 on Colab) and pinning it would make this file
# unusable anywhere else.
#
#   CPU:   pip install torch==2.13.0 torchvision==0.28.0
#   CUDA:  pip install torch==2.13.0 torchvision==0.28.0 \
#              --index-url https://download.pytorch.org/whl/cu128
#
# On Linux, torch pulls `triton` itself; it does not need declaring here.
# ---------------------------------------------------------------------------
torch==2.13.0
torchvision==0.28.0

# ---------------------------------------------------------------------------
# The four frameworks under comparison. These decide the RESULTS, so they are the
# pins that matter most.
#
# sinabs additionally pulls nir, nirtorch and samna (SynSense's chip SDK) -- it will
# not import without them. None is used by this pipeline directly, so they are not
# listed here, but check_env.py reports their versions because they belong in the
# write-up's environment appendix.
# ---------------------------------------------------------------------------
snntorch==1.0.0
norse==1.1.0
spikingjelly==0.0.0.0.14
sinabs==3.1.3

# ---------------------------------------------------------------------------
# Event data
#
# numpy is pinned at 1.26.4, NOT >=2.0 as this file previously said. That range
# contradicted the environment every test and every run so far has used, so a clean
# install from it would have produced a DIFFERENT environment than the validated one.
# 1.26.4 is what the SNNs_2 comparison pipeline pins and what everything here is
# tested against; numba 0.66 and tonic 1.6 are both happy with it.
# ---------------------------------------------------------------------------
tonic==1.6.0
numpy==1.26.4
numba==0.66.0        # compiles fast_denoise -- see event_data_workflow/fast_denoise.py
h5py==3.16.0         # reads .h5 event files (3ET Eyetracking, DSEC)
