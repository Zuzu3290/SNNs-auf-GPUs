Three landmark benchmark publications in the spiking neural network (SNN) and neuromorphic computing domain are NeuroBench (A Framework for Benchmarking Neuromorphic Computing Algorithms and Systems), SNNBench (End-to-end AI-oriented spiking neural network benchmarking), and SpikeNAS-Bench (Benchmarking NAS Algorithms for Spiking Neural Network Architecture). They redefined how the community evaluates brain-inspired systems by shifting focus from isolated software tricks to systematic, hardware-aware, and automated performance measures.1. NeuroBench (A Framework for Benchmarking Neuromorphic Computing Algorithms and Systems)What it did: Created the first comprehensive, community-driven ecosystem combining an Algorithm Track (hardware-independent accuracy and complexity) and a System Track (deployment-aware metrics like real-time latency and energy consumption).How it made them exclusive: Previous metrics like "synaptic operations per second" were ambiguous and detached from real workloads. NeuroBench unified a massive consortium across global institutions to establish standardized tasks (from keyword spotting to motor-cortical control) that directly couple task correctness with explicit energy-cost metrics.2. SNNBench (End-to-end AI-Oriented Spiking Neural Network Benchmarking)What it did: Delivered the first unified, end-to-end evaluation suite explicitly targeting mainstream AI workloads (image classification and speech recognition) across both training and inference stages.How it made them exclusive: Prior SNN evaluations focused heavily on theoretical spike dynamics or only inference accuracy. SNNBench integrated nine distinct workloads combining different learning rules (backprop, unsupervised spike-timing-dependent plasticity), connection topologies, and hardware backends (CPU/GPU) to expose exact performance bottlenecks in deep SNN pipelines.3. SpikeNAS-Bench (Benchmarking NAS Algorithms for Spiking Neural Network Architecture)What it did: Pioneered the first large-scale Neural Architecture Search (NAS) benchmark designed explicitly for SNNs, enumerating a search space of 15,625 candidate Leaky Integrate-and-Fire (LIF) cell structures evaluated across CIFAR and Tiny-ImageNet datasets.How it made them exclusive: Designing SNN layouts traditionally relied on manual translation from conventional deep learning. SpikeNAS-Bench quantified architecture performance and proxy-metric consistency (zero-cost, early-stop, and predictor methods), providing a fixed diagnostic database that automated how optimal spiking cell topologies are discovered.
